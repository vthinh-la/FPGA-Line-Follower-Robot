# Fuzzy Logic Steering Control Architecture

This document provides a mathematical and RTL implementation breakdown of the **Fuzzy Logic Steering Engine** implemented in Verilog HDL, contrasting it against classical PID algorithms for high-speed line-following vehicles.

---

## 1. Why Fuzzy Logic Over Classical PID?

At linear velocities exceeding **1.5 m/s to 3.0 m/s**, line-tracking vehicles suffer from two major dynamic failure modes when regulated by standard Linear PID controllers:
1. **Derivative Kick & High-Frequency Fishtailing**: Discrete IR sensors produce step-function position error jumps. When amplified by $K_D$, this induces severe motor duty spikes, resulting in high-frequency wobble (fishtailing) down straight lines.
2. **Integral Windup at Corner Entry**: Integrating error over sharp 90-degree corners causes motor saturation and delayed recovery upon track exit.

The **FPGA-based Fuzzy Logic Controller** solves this by:
- Operating directly in RTL with **deterministic 1 ms cycle time** ($f_{ctrl} = 1000\text{ Hz}$).
- Segmenting error into **crisp non-linear steering domains** with smooth deadbands.
- Using a dedicated **derivative damping rule** ($FZ\_DAMPING$) to absorb inertial fishtailing without continuous derivative noise.
- Providing **active reverse braking** on the inner wheel during sharp corners.

---

## 2. Sensor Barycenter Error Calculation

The 8 reflective optical sensors ($S_1$ to $S_8$) are weighted symmetrically around the vehicle centerline:

$$\text{Weights}: W = [-7, -5, -3, -1, +1, +3, +5, +7]$$

The instantaneous line error is computed dynamically as:

$$\text{Line\_Error} = \frac{\sum_{i=1}^{8} (S_i \cdot W_i)}{\sum_{i=1}^{8} S_i}$$

- If the line is perfectly centered ($S_4$ and $S_5$ high, others low), $\text{Line\_Error} = 0$.
- In addition, an explicit hardware pattern matcher verifies pure straight track:
  ```verilog
  wire straight_pattern = s3_on && s4_on && s5_on && s6_on && !s1_on && !s2_on && !s7_on && !s8_on;
  ```
  When `straight_pattern` holds, error is forced to zero and the speed booster counter increments.

## 3. Fuzzy Membership Rules

### A. Static Error Rule Set (Fuzzification)
The control variable `fuzzy_steer_base` is mapped based on the filtered error state:

| Filtered Error (`line_error_ctrl`) | Linguistic Term | Crisp Steering Output |
| :---: | :---: | :--- |
| $\le -5$ | **Negative Extreme (NL)** | $+FZ\_STEER\_HARD$ (Hard Left) |
| $-4, -3$ | **Negative Medium (NM)** | $+FZ\_STEER\_MID$ (Medium Left) |
| $-2, -1$ | **Negative Small (NS)** | $+FZ\_STEER\_SOFT$ (Soft Left) |
| $0$ | **Zero (ZO)** | $0$ (Straight Ahead) |
| $+1, +2$ | **Positive Small (PS)** | $-FZ\_STEER\_SOFT$ (Soft Right) |
| $+3, +4$ | **Positive Medium (PM)** | $-FZ\_STEER\_MID$ (Medium Right) |
| $\ge +5$ | **Positive Extreme (PL)** | $-FZ\_STEER\_HARD$ (Hard Right) |

### B. Dynamic Damping Rule Set (Anti-Fishtailing)
Rate of error change is calculated each millisecond:

$$\Delta E = \text{line\_error\_ctrl}[k] - \text{pid\_prev\_error}[k-1]$$

- If $\Delta E \ge +2$ (vehicle is rapidly sliding to the right):
  $$\text{fuzzy\_damping} = -FZ\_DAMPING$$
- If $\Delta E \le -2$ (vehicle is rapidly sliding to the left):
  $$\text{fuzzy\_damping} = +FZ\_DAMPING$$
- Otherwise, $\text{fuzzy\_damping} = 0$.

### C. Defuzzification & Actuation Vector
The unified steering vector is generated by combining static steering with dynamic damping:

$$\text{Vector}_{steer} = \text{fuzzy\_steer\_base} + \text{fuzzy\_damping}$$

This vector directly offsets the base motor PWM duty cycle:

$$\text{Duty}_A = \text{Base\_Duty} - \text{Vector}_{steer}$$

$$\text{Duty}_B = \text{Base\_Duty} + \text{Vector}_{steer}$$

## 4. Cornering Dynamics & Active Reverse Braking

When a corner entry is detected (`s1_on` or `s8_on` or $|E| \ge \text{CORNER\_ENTRY\_ERR\_TH}$):
1. **Base Speed Transition**: Speed drops immediately from `DUTY_FAST` ($60\%$) to `DUTY_SLOW` ($12\%$) or `DUTY_PRE_CORNER` ($20\%$).
2. **Outside Wheel Boost**: Additional drive power `corner_boost` ($10\%$) is added to the outer wheel to swing the chassis into the turn.
3. **Active Reverse Braking**: When the calculated inner wheel duty becomes negative ($	ext{Duty} < 0$), rather than coasting, the FPGA reverses the H-bridge polarity (`IN1 = dir_rev`, `IN2 = dir_fwd`) and applies positive reverse torque to snap the vehicle around tight bends without skidding off track.
